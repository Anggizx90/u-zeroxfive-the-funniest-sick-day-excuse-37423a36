A tiny TypeScript program that writes the funniest single-line reason to call in sick — one line, under 200 characters — to `entry.txt`. The line was picked after three rounds of drafting 22 candidates against the judge's five criteria (see `NOTES.md`).

## Run it

```sh
node main.ts
```

By default it writes to `/output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to write elsewhere:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
